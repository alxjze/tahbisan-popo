# Misericordiam Volo

Situs peringatan tahbisan **Rm. Filipus Frederick Ray Popo, SJ** — 29 Juli 2026.

Satu berkas `index.html` tanpa dependensi dan tanpa proses build. Isinya empat bagian:

- **Beranda** — sambutan dan motto tahbisan.
- **Naungan** — dinding doa. Setiap doa yang dititipkan muncul sebagai seekor anak ayam yang berteduh di bawah sayap induknya.
- **Examen** — panduan lima langkah Examen Ignasian, tersimpan di perangkat masing-masing.
- **Bacaan** — bacaan dan renungan.

## Konfigurasi Supabase

Dinding doa menyimpan titipan doa di Supabase. Dua konstanta di bagian `<script>` `index.html` yang mengaturnya:

```js
const SUPABASE_URL = "https://xxxxxxxx.supabase.co";   // tanpa /rest/v1, tanpa garis miring di akhir
const SUPABASE_KEY = "sb_publishable_...";             // publishable key, aman ditaruh di sisi klien
```

`SUPABASE_URL` harus berupa URL proyek saja. Jalur `/rest/v1/berkat` ditambahkan sendiri oleh kode; kalau ikut ditulis di konstanta, hasilnya URL dobel dan semua permintaan balik **404**.

Kalau kedua konstanta dikosongkan, situs tetap jalan tapi doa hanya tersimpan di `localStorage` perangkat masing-masing.

### Tabel

```sql
create table berkat (
  id         bigint generated by default as identity primary key,
  nama       text not null,
  pesan      text not null,
  created_at timestamptz not null default now()
);

alter table berkat enable row level security;

create policy "siapa pun boleh membaca"   on berkat for select to anon using (true);
create policy "siapa pun boleh menitipkan" on berkat for insert to anon with check (true);
```

Sengaja tidak ada policy `update` dan `delete` — doa yang sudah dititipkan tidak bisa diubah atau dihapus dari sisi pengunjung. Untuk menghapus, lewat Supabase Dashboard.

## Menjalankan secara lokal

```bash
python3 -m http.server 8000
```

Lalu buka `http://localhost:8000`. Membuka berkasnya langsung lewat `file://` juga bisa.
